# geometric_lib

## Описание

Библиотека geometric_lib содержит функции для вычисления площади и периметра геометрических фигур (круга, прямоугольника, квадрата и треугольника).

## Описание функций

### Функции для круга (circle.py)

area(r) — вычисляет площадь круга.

* Параметры: r (int) радиус окружности
* Возвращаемое значение: площадь круга (float)
* Пример вызова: area(5) -> 78.53981633974483

perimeter(r) — вычисляет длину окружности.

* Параметры: r (int) радиус окружности
* Возвращает: длина окружности (float)
* Пример вызова: perimeter(5) -> 31.41592653589793

### Функции для прямоугольника (rectangle.py)

area(a,b) — вычисляет площадь прямоугольника.

* Параметры: a (int) высота прямоугольника
  b (int) ширина прямоугольника;
* Возвращаемое значение: площадь прямоугольника (int)
* Пример вызова: area(4, 5) -> 20

perimeter(a,b) — вычисляет периметр прямоугольника.

* Параметры: a (int) высота прямоугольника
  b (int) ширина прямоугольника;
* Возвращает: периметр прямоугольника (int)
* Пример вызова: perimeter(4, 5) -> 18

### Функции для квадрата (square.py)

area(a) — вычисляет площадь квадрата.

* Параметры: a (int) сторона квадрата
* Возвращаемое значение: площадь квадрата (int)
* Пример вызова: area(4) -> 16

perimeter(a) — вычисляет периметр квадрата.

* Параметры: a (int) сторона квадрата
* Возвращает: периметр квадрата (int)
* Пример вызова: perimeter(4) -> 16

### Функции для треугольника (triangle.py)

area(a,h) — вычисляет площадь треугольника.

* Параметры: a (int) основание треугольника
  h (int) высота треугольника
* Возвращаемое значение: площадь треугольника (float)
* Пример вызова: area(4, 5) -> 10.0

perimeter(a,b,c) — вычисляет периметр треугольника.

* Параметры: a (int) первая сторона
  b (int) вторая сторона
  c (int) третья сторона
* Возвращает: периметр треугольника (int)
* Пример вызова: perimeter(3, 4, 5) -> 12
